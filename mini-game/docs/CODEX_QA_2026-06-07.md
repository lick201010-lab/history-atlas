## Runtime Fix 2026-06-07

Cocos Preview surfaced:

```text
TypeError: Cannot read properties of undefined (reading 'ALL')
```

Cause:

- `ClearFlagBit` was imported from the public `cc` entrypoint, but the sample should use `Camera.ClearFlag`.

Fix:

- `Bootstrap.ts`: `Camera.ClearFlag.SOLID_COLOR`
- `UIController.ts`: `Camera.ClearFlag.DEPTH_ONLY`

Verification:

- Runtime scripts transpile with Cocos-bundled TypeScript.
- `npm run check` passes.
