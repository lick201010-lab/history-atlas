# 微信/抖音小游戏发布说明

## 当前状态

`mini-game/` 只是 Cocos Creator 3.8 拜占庭视觉样板。它还不是可发布小游戏包。

已经完成：

- Cocos 工程结构。
- 拜占庭样板数据导出。
- 主场景 `Main.scene`。
- `Bootstrap` 程序化装配。
- 基础 bundle 目录。

尚未完成：

- 微信小游戏构建配置。
- 抖音小游戏构建配置。
- 平台 adapter。
- 分包与远程资源策略。
- 真机性能验收。

## 推荐发布验证顺序

1. Cocos Creator Preview 能运行样板。
2. Cocos Web Desktop 构建能运行样板。
3. 微信开发者工具能打开构建产物。
4. 抖音开发者工具能打开构建产物。
5. 手机真机能进入拜占庭样板并平滑操作。
6. 与当前网页版本做同视角截图对比。

如果 Cocos 样板没有明显优于网页版本，不应进入全量迁移。
