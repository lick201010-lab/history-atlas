# 已完成里程碑

## 原型与工程化

- 完成单文件 `prototype/index.html` 原型。
- 完成 React 18 + Vite 工程化迁移。
- 形成 `App.jsx` + `MapScene.jsx` + `createBuildingLayer.js` + `mapStyle.js` 的主架构。

## 数据体系成型

- 文明扩展到 43 个。
- 地标扩展到 30 个。
- 时代叙事扩展到 8 个。
- 边界推进到 89 个 GeoJSON feature，支持部分文明多阶段边界。

## 交互系统成型

- 年份驱动的文明显隐。
- 文明信息卡。
- 建筑信息卡。
- 搜索。
- 区域 / 标签筛选。
- 文明锁定。
- 最多两个文明对比。
- 事件项跳转定位。
- 小屏信息面板折叠与移动端 HUD 适配。

## 部署链路打通

- GitHub 仓库建立。
- 阿里云 ECS 上线。
- Caddy 静态服务配置完成。
- `atlas.ckl.hk` 可访问。
- `npm run deploy` 完成自动检查、构建、上传和线上资源校验。

## 视觉与地图方向收束

- 试过 globe.gl 路线后，明确回到 MapLibre 平面地图主线。
- dark 主题成为主要体验方向。
- atlas 主题保留但冻结。
- 海洋与地形分离、边界 glow/casing、HUD 面板、星图装裱等方向已经形成固定语言。

## 样板边界方法形成

- 唐、罗马、哈里发、莫卧儿、玛雅形成早期样板文明。
- 拜占庭边界进一步做了 coastline-aware 拆块和粗糙化处理。
- `docs/BOUNDARY_REFINEMENT_METHODOLOGY.md` 已沉淀成可复用方法论。

## 建筑资产进入 GLB 覆写期

- 圣索菲亚 GLB 管线建立。
- `docs/3D_ASSET_STANDARD.md` 建立资产标准。
- `scripts/lib/wonderKit.mjs` 成为程序化 GLB 生成工具箱。
- 当前已提交并接入 14 个重点奇观 GLB 覆写。
- `scripts/auditGlbAssets.mjs` 与 `docs/GLB_ASSET_BASELINE.md` 建立自动审计基线。

## 协作规则显式化

- 项目内 Obsidian 笔记体系建立。
- `AGENT.md` 加入“Codex 不是附和者，需要基于证据纠错”的协作原则。
- `WORK_LOG.md` 记录平面地图回退、边界精修、圣索菲亚打磨、移动端同步等最近工作流。

## 当前里程碑判断

项目已经跨过：

- 能不能做出来。
- 能不能本地跑起来。
- 能不能上线。
- 能不能用数据驱动地图交互。

现在真正的问题变成：

- 重点边界是否足够可信。
- 重点奇观是否足够有辨识度。
- 地图视角下是否足够精美。
- 文档、验收、自动审计是否能支撑 Claude / Codex 分工继续扩展。
