# 下一步路线图

## 阶段 A：当前体验稳定

目标：让现有暗色地图体验稳定、清晰、可部署。

任务：

- 校验 Claude 最近所有改动。
- 处理未提交文件。
- 确认本地和线上版本一致。
- 推送 GitHub。
- 必要时部署到 `atlas.ckl.hk`。

适合 Codex。

## 阶段 B：边界精修体系

目标：让国家/朝代边界更贴合真实地理。

任务：

- 先做拜占庭、唐、罗马、阿拉伯哈里发、莫卧儿、玛雅样板。
- 每个文明按兴起、鼎盛、衰落分段。
- 使用 Natural Earth 或其他可用参考。
- 保持 `boundaries-simplified.json` 兼容。
- 每次 `npm run validate:data` 和 `npm run build`。

适合 Claude 主做，Codex 验收。

## 阶段 C：奇观模型资产管线

目标：从程序化符号块升级到精品 3D 奇观。

任务：

- 选 5 个样板建筑。
- 为每个找 CC0/可商用参考或做 Blender kitbash。
- 统一 GLB 坐标、尺寸、材质和 AO。
- 接入现有 GLB override。
- 截图验收。

Claude 可做资产脚本和集成，Codex 做质量验收。

## 阶段 D：古地图清晰主题

目标：实现用户喜欢的“立体古地图”感觉，但不牺牲清晰度。

任务：

- 保持海洋平坦深色。
- 陆地采用浮雕质感。
- 文明边界和城市光点高对比。
- 古地图主题作为可切换主题，而不是覆盖暗色主题。

适合 Claude 做实现，Codex 做视觉复核。

## 阶段 E：内容可信度

目标：让项目从“好看”升级到“可信”。

任务：

- 为文明事件加来源。
- 为边界加 sourceNote。
- 为建筑年代和关联文明加来源。
- 建立引用规范。

适合 Claude 批量整理，Codex 抽查。
