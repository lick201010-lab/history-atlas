# 历史沙盘 · 发布验收清单

本清单用于 `https://atlas.ckl.hk/` 的上线前验收。项目根目录：

```text
D:\松君\项目\历史网站
```

上线前必须先完成自动检查，再做一次线上浏览器验收。

## 0. 必跑命令

```bash
npm run check
npm run smoke:release
```

`npm run check` 当前包含：

- `npm run validate:data`
- `npm run test:boundary-outlines`
- `npm run test:boundary-focus`
- `npm run audit:glb`
- `npm run build`

通过标准：

- 数据校验通过：43 个文明、91 个边界 feature、30 个奇观、5 个精修样板。
- 边界 outline 测试通过。
- 边界 focus 测试通过。
- GLB 审计通过：14 OK / 0 WARN / 0 FAIL。
- Vite build 退出码为 0。大 chunk warning 可接受，不阻塞 MVP 上线。
- `npm run smoke:release` 桌面和手机两组均通过，无 console error、page exception、bad app response。

## 1. 线上基础访问

- [ ] 打开 [https://atlas.ckl.hk/](https://atlas.ckl.hk/) 返回正常页面。
- [ ] HTTPS 证书正常。
- [ ] 刷新页面仍能进入应用，不出现 404。
- [ ] 随机 SPA 路径能回退到 `index.html`。
- [ ] 主要 JS / CSS / GLB 资源返回 200。

## 2. 地图基础体验

- [ ] 页面加载后可见深色地图、3D 地形、星空和云层。
- [ ] 加载遮罩最终消失。
- [ ] 鼠标左键拖拽可平移。
- [ ] 滚轮可缩放。
- [ ] 右键拖拽可旋转和俯仰。
- [ ] 右键不弹出浏览器默认菜单。
- [ ] “重置视角”能回到世界视角。
- [ ] “山脉视角”能飞到山地区域，陆地山脉起伏明显。
- [ ] 海洋视觉上保持平、深、干净，不出现明显山脉皱褶。

## 3. 时间轴

- [ ] 时间轴范围是公元前 2000 年到公元 2025 年。
- [ ] 拖动滑块时，年份显示实时更新。
- [ ] 公元前年份显示为“公元前 XXXX”。
- [ ] 公元后年份显示为“公元 XXXX”。
- [ ] 点击关键节点能跳转到对应年份。
- [ ] 年份变化后，活跃文明、领土、都城和奇观同步刷新。

## 4. 文明与边界

- [ ] 活跃文明列表随年份变化。
- [ ] 点击文明列表项，地图能聚焦到该文明。
- [ ] 点击文明边界能打开文明信息卡。
- [ ] 信息卡显示：中文名、英文名、时间、区域、标签、重要性、简介、遗产、事件、相关奇观和边界精度说明。
- [ ] 已选中文明时，非重点文明边界会被压暗，主文明更清楚。
- [ ] 蒙古帝国 1250 年边界没有明显随机内部乱线。
- [ ] 拜占庭、奥斯曼、萨珊、阿契美尼德等重点样板没有明显跨海大色块。
- [ ] 当前边界只作为 MVP 示意范围，不作为学术精确边界。

## 5. 奇观与 3D 模型

- [ ] 奇观总数为 30。
- [ ] 重点 GLB 模型审计通过。
- [ ] 点击奇观列表项后，地图能飞到奇观位置。
- [ ] 选中奇观后，非选中奇观隐藏或弱化，画面更干净。
- [ ] 重点奇观没有倒置、悬空、沉入地下的明显问题。
- [ ] 圣索菲亚、紫禁城、吴哥窟、吉萨金字塔能看出各自的主体形态。
- [ ] “沉浸”按钮能进入干净观赏模式。
- [ ] 退出沉浸模式后，HUD 和时间轴恢复。

## 6. 搜索、筛选和对比

- [ ] 搜索“唐”等关键词能匹配文明或奇观。
- [ ] 选择搜索结果后，地图能飞到目标。
- [ ] 图层开关“领土 / 都城 / 建筑”可独立启用和关闭。
- [ ] 区域和标签筛选能影响文明列表。
- [ ] “清除筛选”能恢复列表。
- [ ] 文明对比最多保留 2 个条目。
- [ ] 第 3 个对比项会提示不能继续添加。

## 7. 移动端

- [ ] 390px 宽度下页面没有水平溢出。
- [ ] 时间轴、信息卡和列表可操作。
- [ ] 选中“玛雅文明”能打开文明卡，而不是误触奇观卡。
- [ ] 沉浸模式下底部小铭牌不出屏。
- [ ] 主要按钮可点击，不被地图 canvas 抢事件。

## 8. 控制台和性能

- [ ] 线上烟测无 console error。
- [ ] 线上烟测无 page exception。
- [ ] 线上烟测无 app 资源 400/500。

## 10. 上线前禁止事项

除非发现 P0 阻塞问题，上线前不要做：

- 大批量新增文明边界。
- 大批量新增 GLB 模型。
- 更换地图引擎、投影或瓦片源。
- 大改 HUD 视觉结构。
- 迁移 Caddy / Nginx / 服务器架构。

明天上线目标优先于继续扩功能。上线前只修硬阻塞和明显破坏体验的问题。
